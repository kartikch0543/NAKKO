API Reference

NAKKO REST API v2.1 · Base URL: https://api.nakko.in/v2

Authentication

All requests require a Bearer token in the Authorization header.

// Include in all requests Authorization: Bearer <your_jwt_token> // Generate token via login POST /auth/login { "email": "user@example.com", "password": "••••••••", "role": "user" // "user" | "worker" | "dev" }

Endpoints

GET /api/users List all registered users
GET /api/users/:id Get user by ID
GET /api/workers List all workers with filters
GET /api/workers/nearby?lat=&lng=&radius= Find workers near a location
POST /api/bookings Create a new booking
GET /api/bookings/:id Get booking details
PUT /api/bookings/:id/status Update booking status
GET /api/payments List payment transactions
DEL /api/users/:id Deactivate user account
